# cairn-data-models

Data model documentation for Cairn, an AI assistant that walks families through the logistics of a death.

## Contents

- [cairn-conceptual-data-model.md](cairn-conceptual-data-model.md): cloud-agnostic conceptual ER diagram covering the relational store, document store, and object store.

## Viewing

The diagrams use Mermaid, which GitHub renders natively in Markdown files.
See https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams
