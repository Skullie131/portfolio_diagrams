# cairn-data-models

Data model documentation for Cairn, an AI assistant that walks families through the logistics of a death.

## Contents

- [cairn-mvp-data-model.md](cairn-mvp-data-model.md): the reduced model for the MVP (sign up, case creation, deceased and user details, four-week journey). Includes the decision log for journey content (content-as-code loaded into relational tables).
- [cairn-conceptual-data-model.md](cairn-conceptual-data-model.md): the full cloud-agnostic conceptual model covering the relational store, document store, and object store.
